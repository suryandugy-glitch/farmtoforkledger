# FarmToFork Ledger
Supply Chain Transparency for Local Produce

## 🎯 Problem
- Up to 30% of food products globally are mislabeled or adulterated
- Farmers receive as little as 15-20% of the final retail price
- Zero traceability in current supply chains

## 💡 Solution
A QR-code-based supply chain transparency platform that provides:
- Instant product history access via scan
- Complete journey visualization from farm to table
- Authenticity guarantee through verifiable data
- Price transparency showing farmer compensation

## 🛠️ Tech Stack
- Frontend: React.js
- Backend: Node.js/Express
- Database: PostgreSQL (simulated for MVP)
- QR Code Generation/Scanning

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/your-username/farmtoforkledger.git`
2. Navigate to project: `cd farmtoforkledger`
3. Install dependencies:
   ```bash
   # Install server dependencies
   cd server
   npm install
   
   # Install client dependencies  
   cd ../client
   npm install
   ```
4. Start backend: `npm start` (in server folder)
5. Start frontend: `npm start` (in client folder)
6. Visit http://localhost:3000
